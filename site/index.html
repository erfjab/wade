Wadefor windows

Alt+Tab, as a row of cards.

Wade replaces the Windows switcher with your open windows laid out side by side, live, like recent apps on a phone. Hold Alt, tap Tab, let go.

What it does

Small, quick, and out of the way.

live

Real previews

Windows draws each card itself with DWM thumbnails, so videos keep playing and text stays sharp. Wade copies no images.

0 % cpu

Idle means idle

When the switcher is closed, no timer or loop runs. The keyboard hook sits on its own thread and only posts messages.

tap

Quick switch

A fast Alt+Tab, pressed and released, jumps straight to the previous window without drawing anything.

↑ close

Close from the row

Press ↑ or Delete, or drag the middle card up, to close a window without leaving the switcher.

motion

Zooms where it should

Your window shrinks into the row from where it sits, and the card you pick grows back onto the real window. With Windows animations off, Wade skips them too.

admin

Works over games

Wade runs as administrator by default, so Alt+Tab also works while a game or launcher run as administrator has focus. It asks once, on the first start.

Install

One line in PowerShell.

The same command installs Wade the first time and updates it later. If the download fails, the installed version is left as it was.

powershell
❯ irm https://raw.githubusercontent.com/erfjab/wade/master/install.ps1 | iex

Installs to %LOCALAPPDATA%\Programs\Wade. On the first start Wade asks once for administrator rights. Windows 10 and 11.
